O que é?
É o documento que informa todos os seus vínculos, remunerações e contribuições previdenciárias,  encontrados no Cadastro Nacional de Informações Sociais (CNIS).
É possível verificar 3 (três) tipos de extratos:
Relações Previdenciárias -
com informações dos períodos trabalhados e/ou contribuídos;
Relações Previdenciárias e Remunerações
-
com informações dos períodos trabalhados e/ou contribuídos e os valores das remunerações;
Ano Civil -
com informações das contribuições, ano a ano, a partir de 11/2019.
